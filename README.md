# 🏨 Grand Stay – Hotel Management System

### ✨ A Modern Desktop Solution for Hotel Operations

**Grand Stay** is a Windows-based Hotel Management System developed to simplify and organize everyday hotel operations through a centralized desktop application.

Built using **C# Windows Forms, .NET Framework 4.8, and Microsoft SQL Server**, this application provides an intuitive interface for managing hotel information, reservations, rooms, billing, and other essential hotel activities.

🎯 Developed by **Hardik Patel**, with a focus on practical functionality, a modern user interface, and opportunities for further customization.

---

## 🌟 About Grand Stay

Managing hotel operations manually can become complicated as the number of rooms, reservations, guests, and billing activities increases.

Grand Stay aims to bring these operations together in one desktop application, helping hotel administrators manage information efficiently through an organized interface and centralized database.

The software is designed for **single-hotel operations** and can serve as a foundation for additional modules and customized business requirements.

## 🚀 Key Features

### 📊 Dashboard
- Centralized dashboard for hotel operations.
- Overview of important hotel information.
- Visual presentation of operational data.
- Charts and statistics for quick insights.

### 🛏️ Room Management
- Manage hotel room information.
- Organize room records and availability.
- Maintain room-related information.

### 📅 Reservation Management
- Manage guest reservations.
- Maintain booking information.
- View and organize reservation records.

### 💳 Billing Management
- Manage guest billing information.
- Maintain billing records.
- Organize payment-related information.

### 🛎️ Hotel Services
- Manage additional hotel services.
- Maintain service-related records.
- Integrate service information into hotel operations.
