# 🏨 Grand Stay – Installation Guide

Welcome to **Grand Stay – Hotel Management System!**

This guide explains how to download, install, and launch Grand Stay on your Windows computer.

The application is distributed through a Windows installer created using **Inno Setup**, making the installation process simple and straightforward.

---

## 💻 1. System Requirements

Before installing Grand Stay, ensure your computer meets the following requirements.

### Operating System
- Windows 10
- Windows 11

### Software Requirements
- .NET Framework 4.8
- Windows-compatible desktop environment

### Recommended Hardware
- RAM: 8 GB
- Processor: Dual-Core or better
- Storage: Sufficient free disk space for installation

---

## 📥 2. Download Grand Stay

Follow these steps to download the latest version.

1. Visit the official Grand Stay GitHub repository.
2. Navigate to the **Releases** section.
3. Open the latest available release.
4. Download the Windows installer.

**Installer filename example:**

`GrandStay_Setup_v1.0.2.exe`

> 💡 Always download the latest available release from the official repository.

---

## 🚀 3. Install Grand Stay

Once the installer has been downloaded:

1. Locate the downloaded setup file.
2. Double-click the installer to start the setup wizard.
3. If Windows displays a User Account Control prompt, review it and allow the installer to proceed if you trust the downloaded file.
4. Follow the instructions displayed by the installation wizard.
5. Review and accept the software license terms.
6. Choose the installation location if prompted.
7. Continue with the installation.
8. Wait for the installation process to complete.
9. Click **Finish** to close the setup wizard.

🎉 Grand Stay is now installed on your computer!

---

## 🖥️ 4. Launch the Application

After successful installation, you can open Grand Stay using any available launch option:

- **Desktop Shortcut:** Double-click the Grand Stay desktop shortcut, if created during installation.
- **Start Menu:** Search for Grand Stay in the Windows Start Menu.
- **Installation Directory:** Open the installation folder and launch the application executable.

The application will display its splash screen followed by the login screen.

---

## 🔐 5. Login to Grand Stay

After launching the application:

1. Wait for the splash screen to complete.
2. The login screen will appear.
3. Enter your authorized login credentials.
4. Complete the login process to access the application dashboard.

> 🔒 Login credentials must be provided or configured through the application's authorized setup process. Do not assume default credentials unless they have been officially supplied.

---

## ⚠️ 6. Troubleshooting

### Application does not launch
- Ensure your Windows operating system is supported.
- Verify that .NET Framework 4.8 is installed.
- Try launching the application again.
- If the issue continues, contact the developer.

### Installation is blocked by Windows
- Verify that the installer was downloaded from the official Grand Stay repository.
- Check the Windows security notification.
- Only proceed if you trust the installer and its source.

### Login is unsuccessful
- Verify that the entered credentials are correct.
- Check whether your account has been configured and authorized.
- Contact the administrator or developer if the issue persists.

### Application displays an unexpected error
- Restart the application.
- Restart Windows if necessary.
- Note the error message and share it with the developer for assistance.

---

## 🔄 7. Updating Grand Stay

When a new version becomes available:

1. Visit the official GitHub Releases page.
2. Download the latest installer.
3. Follow the installation wizard.
4. Launch the updated application.

Before updating, make sure any important application data is backed up if your installation or database configuration requires it.

---

## 🗑️ 8. Uninstall Grand Stay

If you want to remove Grand Stay:

1. Open Windows Settings.
2. Navigate to **Apps → Installed Apps**.
3. Search for Grand Stay.
4. Select the application.
5. Click **Uninstall**.
6. Follow the removal instructions.

Alternatively, use the application's uninstaller if it is available in the installation directory.
